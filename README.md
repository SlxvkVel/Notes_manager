# 🗒️ Notes Manager -  менеджер заметок
### 🔧 Микросервисы
- **auth-service** - Аутентификация и авторизация (Go)
- **notes-service** - Управление заметками (Go) 
- **frontend** - Веб-интерфейс (Nginx + HTML/JS)
- **postgres** - База данных
- **redis** - Кэширование и сессии
